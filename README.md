# School Management System

A web app for running a school: students, classes, attendance, fees, exams and report cards.

I'm building it step by step to learn full-stack web development from scratch.

## Planned features

- [ ] Login with roles (admin, teacher, student, parent)
- [ ] Students and classes
- [ ] Attendance
- [ ] Fees and receipts
- [ ] Exams and report cards
- [ ] Dashboard with charts

## Tech stack

| Part | Tool | What it does |
|------|------|--------------|
| Frontend | React + Vite | The screens users see and click |
| Backend | Node.js + Express | The server: rules, logins, calculations |
| Database | SQLite → PostgreSQL (via Prisma) | Where all records are stored |
